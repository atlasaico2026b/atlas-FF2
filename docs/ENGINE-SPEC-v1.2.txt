TANK FOAM & FIRE-WATER CALCULATION ENGINE SPECIFICATION v1.2
Deterministic Engineering Calculation Reference — English Formula/Rule Set
Design Basis Profile: NFPA 11-2024 + NFPA 15-2022 + NFPA 30-2024 + project-selected editions of NFPA 20/22/24. The standards edition is a locked configuration value; the engine shall not silently switch editions.
Supported Fuels: Gasoline, Premium Gasoline, Diesel Fuel, Kerosene, Naphtha, Crude Oil, Sour Crude Oil, Oil-Contaminated Material (ORD).
Deterministic Rule: Every numeric design value shall originate from an explicit input, reference-table record, manufacturer/listing record, or defined formula. Missing required values shall stop the affected calculation.

5. LOOKUP / SELECTION ALGORITHMS
ID
| Algorithm
| Rule
LOOK-001
| Fuel classification
| Classify from explicit NFPA 30 input properties; do not classify from fuel name alone.
LOOK-002
| Fixed-roof outlet count
| Select minimum row whose diameter condition contains D; apply explicit additional-area rule only when D exceeds table maximum.
LOOK-003
| Foam rate/time
| Select table record by roof type + discharge method + hydrocarbon condition + product listing override.
LOOK-004
| Floating-roof method
| Select Top-of-Seal or Below-the-Seal/Weather-Shield only when seal construction constraints are satisfied.
LOOK-005
| Internal floating roof
| Allow seal-only only for listed roof constructions; otherwise require full-surface protection.
LOOK-006
| Cooling density
| Select NFPA 15 vessel exposure density = 4.1 L/min/m² for exposed vessel surface unless a project/test/listing rule explicitly changes it.
LOOK-007
| Cooling ring spacing
| S_vertical_max = MIN(3.7 m when rundown criterion applies, S_vertical_listed).
LOOK-008
| Cooling nozzle spacing
| Use nozzle listing/pattern coverage. If no circumferential coverage value exists, return INPUT_REQUIRED.
LOOK-009
| Equipment selection
| Filter equipment library by listing/approval, flow range, pressure range, concentration compatibility, temperature, material compatibility, then select the first project-approved candidate meeting all constraints.
LOOK-010
| Pump selection
| Select from pump curve library; candidate is valid only if curve covers the required duty point and all project/NFPA constraints.
LOOK-011
| Jockey pump
| Use project-defined maintenance/leakage design basis; no universal hard-coded jockey flow is permitted.
LOOK-012
| Monitor count
| Coverage-driven geometry calculation using listing reach/angles/trajectory; no universal fixed monitor count is permitted.

calculateCooling(tank, nfpa15):     A_shell = PI * tank.D * tank.H_cooling     A_top = tank.topCoolingRequired ? PI*tank.D*tank.D/4 : 0     A = A_shell + A_top     R = nfpa15.vesselExposureDensity     Q = A * R     S_vertical = min(tank.nozzle.verticalSpacingListed,                      3.7 if tank.rundownCriterion else tank.nozzle.verticalSpacingListed)     if S_vertical is null:         return ERROR('INPUT_REQUIRED')     N_rings = max(1, ceil(tank.H_cooling / S_vertical))     S_circ = tank.nozzle.circumferentialSpacingListed     if S_circ is null:         return ERROR('INPUT_REQUIRED')     N_per_ring = max(1, ceil(PI*tank.D / S_circ))     return {A, R, Q, N_rings, N_per_ring}

12. SITE RING MAIN / MONITOR / HYDRANT LOGIC
Function
| Deterministic Rule
Ring main segment flow
| Q_segment = SUM(all active downstream demands) for a tree network; for loops, solve nodal continuity + energy equations.
Ring main pressure
| P_node = P_source − elevation loss − friction loss − minor losses; every required terminal node must satisfy minimum pressure.
Diameter iteration
| Evaluate candidate diameters from project pipe-size library; select smallest candidate that passes all scenario cases.
Monitor flow
| Use manufacturer/listed flow-pressure curve or K-factor; do not derive a universal flow from nozzle size name.
Monitor count
| Generate candidate positions, calculate coverage geometry, reject blind zones, then select minimum count satisfying coverage and access constraints.
Hydrant count
| Generate candidate locations from site access/coverage rules; verify simultaneous active hydrant demand in scenario hydraulic cases.
Worst-case monitors
| Use the project simultaneous-operation rule; do not assume all installed monitors operate simultaneously unless explicitly configured.
Worst-case hydrants
| Use the project simultaneous-operation rule; do not assume all installed hydrants flow simultaneously unless explicitly configured.

17. NON-NEGOTIABLE ENGINE RULES
1. No invented numeric values. 2. No implicit defaults for engineering inputs. 3. No alternative formula outside the Formula Repository. 4. No standard-value lookup by fuel name alone. 5. No intermediate rounding. 6. No equal flow split for hydraulic loops. 7. No equipment acceptance without listing/approval and operating-range validation. 8. No universal cooling nozzle spacing without manufacturer/listed coverage data. 9. No universal monitor count or hydrant count without site coverage/access criteria. 10. Worst-case pump flow and worst-case storage volume are selected independently. 11. External floating-roof sunken/full-surface protection shall not receive a fabricated fixed-system rate/time. 12. Every result stores Formula ID, Reference Table ID(s), standard profile, inputs and validation status. 13. If a standard table is not applicable to the selected fuel/roof/scenario, return METHOD_NOT_PERMITTED or STANDARD_VALUE_NOT_DEFINED. 14. UI labels shall display source IDs for traceability. 15. Any manual engineering override shall be explicitly stored, versioned and marked MANUAL_OVERRIDE.

راه‌اندازی در VS Code:
۱. فایل ZIP را دانلود و استخراج کنید (راست‌کلیک ← Extract All)
۲. پوشه atlas-fire-system را در VS Code باز کنید
۳. نصب پکیج‌ها: npm install
۴. اجرا: npm run dev:full
۵. مرورگر: http://localhost:3000
